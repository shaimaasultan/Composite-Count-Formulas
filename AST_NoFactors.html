No-Factors AST Builder

Represents any whole number as sums of only the blocks {5, 6, 7, 11, 17} — no 1/2/3 filler (if a big block would force a leftover +1/+2, it pops one and uses smaller blocks instead: 30 = 17+7+6, not 17+11+2). Only the six gaps {1,2,3,4,8,9} can't be done. No factorization is ever used. Decompose shows the repeated sums; Fold collapses equal blocks into count·block products; Collect common term first divides out any 2 and 3 (as 2·(), 3·()), then on the remaining number tries each block d as a shared term — it collects (d·(M/d), e.g. 143 = 13·11) exactly when d divides it. So it finds factors 2, 3 and any block factor. Collect all repeats this — peel a block, collect again on the cofactor, and so on until no block divides — giving N = 2a·3b·5c·7d·11e·17f · residual. Builds the canonical tree over {1,2,3,+,−,*}. Blocks decode as 5=2·3−1, 6=2·3, 7=2·3+1, 11=2·3·2−1, 17=2·3·3−1. Uses BigInt.
